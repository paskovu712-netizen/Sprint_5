# Проект автоматизации тестирования UI сайта Stellar Burger
1. Основа для написания автотестов — фреймворк pytest.
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest -v.
4. Для написания тесттов используется Selenium WebDriver
5. Тесты настроены на драйвер для браузера Chrome
